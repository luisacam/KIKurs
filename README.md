# KIKurs - Einführung in Künstliche Intelligenz

Ein praktischer Kurs zum Erlernen von KI und Machine Learning Grundlagen.

## Kursinhalt

### Lektionen

1. **Einführung in KI** - Was ist Künstliche Intelligenz?
2. **Machine Learning Grundlagen** - Überwachtes und unüberwachtes Lernen
3. **Neuronale Netze** - Wie funktionieren sie?
4. **Praktische Anwendungen** - KI im Alltag

### Struktur

```
KIKurs/
├── lektionen/           # Theoretische Inhalte
│   ├── 01-einfuehrung/
│   ├── 02-ml-grundlagen/
│   ├── 03-neuronale-netze/
│   └── 04-praxis/
├── uebungen/            # Praktische Aufgaben
├── beispiele/           # Code-Beispiele zum Ausprobieren
└── daten/               # Datensätze für Übungen
```

## Voraussetzungen

- Grundlegende Programmierkenntnisse (Python empfohlen)
- Interesse an KI und Machine Learning
- Python 3.8+ installiert

## Installation

```bash
# Repository klonen
git clone https://github.com/luisacam/KIKurs.git
cd KIKurs

# (Optional) Virtuelle Umgebung erstellen
python -m venv venv
source venv/bin/activate  # Linux/Mac
# oder: venv\Scripts\activate  # Windows

# Abhängigkeiten installieren
pip install -r requirements.txt
```

## Erste Schritte

1. Starte mit der ersten Lektion in `lektionen/01-einfuehrung/`
2. Bearbeite die zugehörigen Übungen in `uebungen/`
3. Experimentiere mit den Beispielen in `beispiele/`
