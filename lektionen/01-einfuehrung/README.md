## Was ist Künstliche Intelligenz?

**Künstliche Intelligenz (KI)** ist ein Teilgebiet der Informatik, das sich damit beschäftigt, Maschinen so zu programmieren, dass sie Aufgaben erledigen können, die normalerweise menschliche Intelligenz erfordern.

### Beispiele für KI im Alltag

| Anwendung | Beschreibung |
|-----------|--------------|
| Sprachassistenten | Siri, Alexa, Google Assistant |
| Empfehlungssysteme | Netflix, Spotify, YouTube |
| Übersetzung | DeepL, Google Translate |
| Bildererkennung | Gesichtserkennung, Foto-Apps |
| Chatbots | ChatGPT, Claude |

## Arten von KI

### 1. Schwache KI (Narrow AI)
- Spezialisiert auf eine bestimmte Aufgabe
- Kann diese Aufgabe oft besser als Menschen
- **Beispiel:** Schach-Computer, Spamfilter

### 2. Starke KI (General AI)
- Könnte jede intellektuelle Aufgabe eines Menschen ausführen
- Existiert noch nicht
- Ziel der KI-Forschung

## Machine Learning

**Machine Learning (ML)** ist eine Methode der KI, bei der Computer aus Daten lernen, anstatt explizit programmiert zu werden.

```
Traditionelle Programmierung:
    Daten + Regeln → Programm → Ergebnis

Machine Learning:
    Daten + Ergebnisse → Algorithmus → Regeln (Modell)
```
